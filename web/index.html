Core System Capabilities

Designed for college evaluation, clean code standards, and real-world utility

Income & Expense Tracking

Categorize transactions into Food, Shopping, Travel, Education, and Bills with payment methods and custom notes.

Automated Budget Alerts

Set custom category spending limits and receive automated warnings (80%) and alerts (100% exceeded) in real time.

Java File Handling

Transactions and budgets are persisted safely in transactions.txt and budgets.txt using BufferedReader & BufferedWriter.

Pure OOP Architecture

Implements Encapsulation (private fields), Inheritance (Transaction → Income & Expense), Collections (ArrayList & HashMap), and Polymorphism.
